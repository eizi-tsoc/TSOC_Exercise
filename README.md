# TSOC Exercise Web v1.0.0

Excel原版 `TSOC_Exercise_2v4.xlsm` を基準にした初回Web移植版です。

## GitHub Pages
1. このフォルダの中身をGitHubリポジトリへ配置します。
2. Repository Settings → Pages で `main` ブランチの root を公開対象にします。
3. `index.html` がトップ画面です。ビルド処理は不要です。

## 初版で再現した機能
- 7カテゴリーの運動表示・選択
- 原版4プリセット（野球パターン／腰痛体操／肩体操／膝体操）を候補表示として再現し、その中から個別選択
- 最大8種目の選択制限
- 患者名
- 回数または秒、セット数の入力
- 4種目×2ページの印刷/PDF保存
- 原版に埋め込まれた運動画像の利用
- 検索（Web版の操作補助。原版データは変更しません）

## 保存について
v1.0.0では患者情報・発行履歴をサーバーへ保存しません。ブラウザ印刷からPDF保存できます。患者ID＋発行日によるファイル管理、カルテ貼付用サマリーは次段階の機能として追加できる構造にしています。
