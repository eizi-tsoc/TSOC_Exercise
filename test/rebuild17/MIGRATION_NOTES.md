# Migration Notes — v1.2.1

## 現行ExcelからWebへの置換
- 選択用Excelのカテゴリー/運動情報をWeb上の運動マスターへ統合。
- 印刷用Excel Sheet7 のQR画像を全218運動へ対応付け。
- 印刷用Excel Sheet4 のヘッダー構成、4枠固定、空き枠ロゴの考え方をWeb印刷へ反映。

## v1.1.0 からの変更
- デスクトップ操作では中央運動一覧だけがスクロールし、左右ペインを常時参照できる構成へ変更。
- 選択済み運動のサムネイル、▲/▼順序変更、プルダウン式回数/時間・セット数を追加。
- プルダウン候補は `data/app-config.js` へ分離。

## 保留
- Excel上の矢印等の図形オーバーレイは、後日完成画像へ置換する。
- 高解像度印刷画像への切替機構は後続版で実装する。
- 空き枠ロゴは現行フォームの意匠をWeb/CSSで再現した暫定版。最終固定画像が用意できれば差し替える。


## v1.2.1
- 印刷画像は `print_images` / `print_image_transforms` を任意で持てる。
- 未設定時は既存 `images` / `image_transforms` を使用するため、画像移行は運動単位で段階的に実施可能。
- 元印刷用Excelの `xl/media` にある高解像度素材は、運動IDとの対応を確認してから登録する。
