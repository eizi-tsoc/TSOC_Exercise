# Changelog

## v1.2.1
- 印刷ヘッダーの患者氏名表記を「患者様」から「様」のみに修正。
- 選択画面用画像と印刷/PDF用高解像度画像を分離できる二層構造を実装。
- 運動データに `print_images` が設定されている場合は印刷時に高解像度画像を優先使用する。
- `print_images` が未設定の場合は、従来の `images` を自動使用するフォールバックを実装し、既存218運動の印刷を維持。
- 印刷用画像専用の回転情報として `print_image_transforms` を利用可能にした。未設定時は選択用画像の回転情報を継続使用。
- 高解像度画像は今後、元印刷用Excelの `xl/media` から整理・対応付けして段階的に登録する。

## v1.2.0
- 左カテゴリー、右選択済みパネルを常時表示し、中央の運動一覧のみ縦スクロールするデスクトップレイアウトへ変更。
- 選択済み運動を写真付きカード表示へ変更し、視認性を向上。
- 選択後の印刷順を「▲ / ▼」で上下入れ替え可能にした。ドラッグ操作は使用しない。
- 回数/時間を 1～10 / 20 / 30 / 40 / 60 から選択可能にした。
- セット数を 1～10 から選択可能にした。
- 回数/時間・セット数の選択肢を `data/app-config.js` に分離し、今後変更しやすい構造にした。
- 印刷フォームを現行 `TSOC_Exercise_2v4_output.xlsm` Sheet4 に近づけて再構築。
- 全218運動に現行印刷用Excel由来のQR画像を対応付け、印刷/PDFへ表示。
- 現行のTSOCヘッダーロゴを印刷フォームへ追加。
- 1ページ4枠を固定し、選択運動が4つ未満の場合は空き枠へTSOCロゴ風プレースホルダーを表示。
- 5～8運動選択時は2ページ目を生成し、2ページ目の空き枠も同様に補完。
- Excel上の赤矢印等の図形は、後日完成画像へ置換する方針を継続。

## v1.1.0
- 11シートをすべてカテゴリーとして統一。
- 同一運動の複数カテゴリー所属へ対応。
- 画像回転情報を反映。
- A4横・4種目/ページの印刷骨格を実装。
