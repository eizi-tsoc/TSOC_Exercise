Rebuild21 Save / Publish UI + Version

【保存と公開の整理】
・新規・未公開
  「下書き保存」= 管理画面内に保存するだけ。選択画面には出ない。
  「公開する」= 初回公開。選択画面に表示する。

・公開中（既存218運動 / 一度公開済みの新規運動）
  「変更を保存」= 保存と同時に選択画面へ反映。
  「公開する」は表示しない。

・非表示中
  「変更を保存」= 内容は保存。
  選択画面には表示しない。

【バージョン表示】
選択画面と管理画面の右下に
「GitHub TEST Rebuild21」
を常時表示。
GitHubへアップロードしたファイルが新しい版へ切り替わったか目視確認できます。

【主な確認】
1. 新規運動を保存 → ボタン名が「下書き保存」
2. 下書き保存だけでは選択画面に出ない
3. 「公開する」で選択画面に出る
4. 公開後の編集では「変更を保存」
5. 既存運動でも「変更を保存」
6. 選択画面・管理画面右下に GitHub TEST Rebuild21
