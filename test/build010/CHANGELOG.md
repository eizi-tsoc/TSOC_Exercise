# Changelog

## v2.1.0 / Build017 (2026-09-08)
- 管理画面の日本語QR・English QRの入力UIを統一。日本語QR入力を日本語ブロック内（説明文の直後）へ移設し、「日本語 → English → 共通設定」の順に整理。日本語QRにもURL/画像の切替とプレビューを追加し、English QRと同じ操作感にした。
- 日本語QRブロックに固有ID `fJapaneseQrBox` を付与し、取得セレクタをクラス指定から固有ID指定へ厳密化。English QRとの取り違えを防止。
- English専用運動 EX219 のカテゴリー自動設定（`Training(Upper limb)`）を削除。利用画面に不要なカテゴリーが表示されないようにした。代替カテゴリーは自動設定せず、ユーザーが管理画面から設定する方針とした。EX219の手動登録画像・レイアウト・English QRには影響しない。
- 表示順編集モーダルの各行に運動画像サムネイルを追加。既存の完成画像を使用し、EX219等のローカル画像にも対応。並び替え操作（▲▼／上端・下端）は従来どおり維持。
- （実機確認修正）表示順編集で、EX219等のIndexedDB画像を持つ手動登録運動のサムネイルが空欄になる不具合を修正。表示順サムネイルを imageURL() 経由のIndexedDB優先読み込みに変更し、IndexedDB画像がなければ既存の完成画像を使用するようにした。admin.jsの表示順サムネイル生成処理のみ変更で、保存構造・既存218件・storage仕様への影響なし。Build番号は017のまま維持（正式タグ付け前の実機確認修正）。
- English PDFの単位表記を修正。秒の表記を `sec` から `seconds` に統一（reps / sets は既存のまま）。日本語表記（回／秒／セット）は変更なし。
- 出力言語の初期未選択・PDF作成前の言語チェック・言語切替時に選択運動を解除しない仕様は、Build016の実装をそのまま維持。
- 保存データ構造（English QRの `EN:${EXID}` 方式、`tsoc_admin_language_data_v1` ほか）、test/production ストレージ分離、PDFのアスペクト比維持、QR 26mm、バックアップ/復元、既存218件の画像レイアウト・完成画像には変更なし。


## v1.2.1
- 印刷ヘッダーの患者氏名表記を「患者様」から「様」のみに修正。
- 選択画面用画像と印刷/PDF用高解像度画像を分離できる二層構造を実装。
- 運動データに `print_images` が設定されている場合は印刷時に高解像度画像を優先使用する。
- `print_images` が未設定の場合は、従来の `images` を自動使用するフォールバックを実装し、既存218運動の印刷を維持。
- 印刷用画像専用の回転情報として `print_image_transforms` を利用可能にした。未設定時は選択用画像の回転情報を継続使用。
- 高解像度画像は今後、元印刷用Excelの `xl/media` から整理・対応付けして段階的に登録する。

## v1.2.0
- 左カテゴリー、右選択済みパネルを常時表示し、中央の運動一覧のみ縦スクロールするデスクトップレイアウトへ変更。
- 選択済み運動を写真付きカード表示へ変更し、視認性を向上。
- 選択後の印刷順を「▲ / ▼」で上下入れ替え可能にした。ドラッグ操作は使用しない。
- 回数/時間を 1～10 / 20 / 30 / 40 / 60 から選択可能にした。
- セット数を 1～10 から選択可能にした。
- 回数/時間・セット数の選択肢を `data/app-config.js` に分離し、今後変更しやすい構造にした。
- 印刷フォームを現行 `TSOC_Exercise_2v4_output.xlsm` Sheet4 に近づけて再構築。
- 全218運動に現行印刷用Excel由来のQR画像を対応付け、印刷/PDFへ表示。
- 現行のTSOCヘッダーロゴを印刷フォームへ追加。
- 1ページ4枠を固定し、選択運動が4つ未満の場合は空き枠へTSOCロゴ風プレースホルダーを表示。
- 5～8運動選択時は2ページ目を生成し、2ページ目の空き枠も同様に補完。
- Excel上の赤矢印等の図形は、後日完成画像へ置換する方針を継続。
